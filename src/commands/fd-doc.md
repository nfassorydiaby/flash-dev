---
description: Met à jour la documentation impactée par une story
argument-hint: <story-id>
---

Phase DOC pour la story $ARGUMENTS.

1. Détermine ce que la story change de visible : API publique, CLI,
   configuration, comportement utilisateur.
2. Mets à jour README, doc API, changelog, et tout doc utilisateur
   concerné — pas seulement des commentaires de code.
3. Si rien de visible n'a changé, indique-le explicitement plutôt que de
   sauter l'étape silencieusement.
