Phase RESEARCH pour la story $ARGUMENTS.

1. Lis `docs/stories.md` pour retrouver la story $ARGUMENTS et ses
   dépendances.
2. Explore le code existant pertinent, les patterns déjà en place, les
   contraintes techniques, les risques (perf, sécurité, régressions).
3. Écris `docs/research/$ARGUMENTS.md` : ce qui existe déjà, ce qui manque,
   les options d'implémentation possibles et leurs compromis.
4. N'écris et ne modifie aucun fichier de code dans cette commande.
5. Termine en recommandant la suite : /fd-plan $ARGUMENTS.
